# Processed inputs and provenance

These records document known inputs in the separate working package. They are not currently included in this repository. They were identified by inspecting scripts and filenames, not by tracing every read during a fresh end-to-end run. Exact source file versions, processing histories, rights and minimum dependency sets remain to be confirmed before each derived product is republished.
